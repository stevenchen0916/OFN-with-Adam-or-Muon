# Burgers 双 PDE 正式证据：16 核服务器运行包

本轮的两道方程是 **已有热方程 + 新增正式 Burgers 实验**。本包交付数据、冻结协议、训练与分析代码；**Burgers 的正式误差、训练动态和交互结论尚未产生**。服务器跑完才可把第二个 PDE 计入论文证据。

## 上传与启动

把 `Burgers_Server16_20261118.zip` 上传到服务器家目录：

```bash
cd "$HOME"
unzip Burgers_Server16_20261118.zip
cd "$HOME/BurgersProject"
sbatch run_burgers16.slurm
```

默认复用 `$HOME/HeatProject/.venv/bin/python`，以 **4 个训练进程 × 每进程 4 线程 = 16 核**运行。完整入口会依次执行包校验、依赖检查、正确性测试、真实数据九配置短检查、独立调参、冻结学习率、正式训练、最终测试和图表导出。短检查通过后自动进入已授权的正式流程。无需重新生成数据，也无需重新安装原环境。

如果原环境或上传目录不同，使用真实路径：

```bash
sbatch --export=ALL,BURGERS_PY=/实际路径/.venv/bin/python,BURGERS_ROOT=/实际路径/BurgersProject run_burgers16.slurm
```

若先看服务器实测速度，使用：

```bash
sbatch --export=ALL,BURGERS_STAGE=smoke run_burgers16.slurm
```

这条命令只做校验和每配置 200 步短检查。查看 `results16/dry_run_report.json` 的 `budget`；之后提交默认命令会复用检查记录，再开始完整实验。耗时由本台服务器短检查外推，包含采样到的验证与保存开销，**不含学习率边界扩展、排队和持续运行降速**。包内不提供未经服务器实测的完成时间承诺。一次 Slurm 作业上限为 72 小时。

## 已冻结的实验口径

| 项目 | Burgers 设置 | 与热方程的关系 |
|---|---|---|
| 方程 | 周期受迫黏性 Burgers，黏性 0.1，空间与时间均为 [0,1] | 不同 PDE |
| 输入 | 13 个初值传感器 + 13 个空间 forcing 传感器；5 维周期时空特征 | 按 Burgers 输入适配模型 |
| 数据 | 原 2,000 函数固定划分 1,800 训练 / 200 验证；另生成 200 个全新测试函数 | 相同划分规模；测试分布各自定义 |
| 预处理 | 仅训练函数拟合逐特征 min/max；QOFN 增广一维；密集基线使用原始输入；无 PCA | 不照搬热方程 PCA |
| 输出顺序 | 50 个时刻 × 50 个空间点，空间点变化最快 | 不使用热方程的标签转置修复 |
| 模型 | Full、No-Flow、DeepONet、MIONet；p=25、ReLU；参数量差小于 1% | 固定共同容量原则 |
| 配置 | 四架构分别 Adam / Muon–Adam，加 DeepONet 输出矩阵专用 Muon，共九组 | 相同九组逻辑 |
| Muon 分配 | QOFN 三个输出矩阵；标准密集基线全部二维权重；DeepONet 对照只作用两个输出矩阵 | 相同分配原则 |
| 优化器 | 两组 weight decay=0；Muon 使用 match_rms_adamw，无额外手动 shape 缩放 | 相同 |
| 训练 | 全批量 MSE，固定 20,000 更新；两优化器各自 cosine 无重启，末端比例 0.01 | 同预算与调度规则，不声称已收敛 |
| 日志 | 每 500 步完整验证；每 2,000 步完整恢复状态；逐步耗时、门控和特征范数另存 | 相同评价规则 |
| 调参 | 种子 289–291；先选每架构 Adam，再固定其辅助 Adam、独立扫描 Muon | 完全重新在 Burgers 验证集选择 |
| Adam 初始网格 | 1e-4、3e-4、1e-3、3e-3、1e-2 | 共同搜索规则，不复用热方程已选值 |
| Muon 初始网格 | 3e-4、1e-3、3e-3、1e-2、3e-2 | 边界最优继续向外扩展三倍 |
| 调参分数 | 各种子在 19000/19500/20000 步验证相对 L2 的中位数，再跨三种子取均值 | 相同 |
| 正式训练 | 全新种子 292–301，共 90 次；同一种子九组全部终止后再下一种子 | 相同；PDE 间不合并种子 |
| 测试 | 只评估冻结设置的固定第 20,000 步模型；全部计划任务终止后开放测试；缓存一次评分 | 相同最终评价规则 |

基础计划 **135 次调参 + 90 次正式训练 = 225 次完整训练**；学习率边界扩展另计。分阶段搜索不是 Adam/Muon 两学习率的联合最优搜索。

逐函数误差先用全部 2,500 个时空点计算相对 L2，再对 200 个测试函数取算术平均；主表报告十个训练种子的均值和样本标准差。训练曲线使用验证集，测试集不用于选学习率或最好时刻。

核心交互固定为：

```text
I_seed = ln(E_Full,Hybrid / E_Full,Adam)
       - ln(E_NoFlow,Hybrid / E_NoFlow,Adam)
```

负值表示 Full 的比例误差下降更强。报告十种子配对 t 检验及 95% 区间，精确符号枚举 Wilcoxon 仅作敏感性分析。保留正值、零附近、不显著和反向结果。不同架构可选不同学习率，结论条件于本次调参规则。热方程与 Burgers 分别报告，不合并绝对误差或计算跨 PDE 的种子 p 值。

0.06 和 0.045 验证阈值仅为沿用的描述性时间指标；不表示两道方程达到该阈值同样困难，不用于调参或停止。未达到与数值发散分别记录。

## 已做的数据核验

原训练档案 SHA-256 固定；三个样本的原生成器重算精确复现存储目标。核验了初值、周期特征和查询／标签展平顺序。将三个样本的求解空间网格从 256 加密至 512，记录数值敏感性，见 `provenance/DATA_AUDIT.json`。

新测试集从相同的原 GRF、幅值和求解器配方生成，两个随机数种子分别记录；与原训练输入没有逐位重复。没有打开旧 `BU_test.npz`。新测试目标在制备阶段生成和保存，未进行任何模型测试评分；训练／调参入口禁止读取测试数组。新旧目标都使用原求解器到达标签时刻后的首个时间步快照。当前任务比较这个指定离散目标；三样本加密不等于连续 PDE 误差的严格上界。

原训练生成种子未保存。QOFN 对验证／测试输入沿用训练上下界，超出训练范围时保留原变换，不用验证／测试数据重拟合。

数值发散保留为该种子原状态，不换种子或临时换学习率。没有完整十种子时，完整主结果明确不可用；可用子集只能作为探索性。测试评分若在事务中断，程序会保留 `.pending.json` 并停止，先核查该记录，避免静默重复评分。
